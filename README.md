# ✅ To-Do List App

A simple, interactive To-Do List web application built using **HTML, CSS, and JavaScript**. It helps users organize tasks, mark completed items, and manage their task list through a straightforward interface.

## ✨ Features

- ➕ **Add Tasks** — Add new tasks to your list.
- ☑️ **Complete Tasks** — Mark tasks as completed.
- 🗑️ **Delete Tasks** — Remove individual tasks.
- 🧹 **Clear Completed Tasks** — Remove completed items from the list.
- ⚡ **Interactive Interface** — Update the task list without manually editing the page.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 📂 Project Structure

```text
To-Do-List/
├── index.html
├── style.css
└── script.js
```

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Start adding and managing your tasks!

No installation or build tools are required.

## 🎯 Project Purpose

This project was created to practice front-end web development, DOM manipulation, JavaScript event handling, and dynamically updating webpage content.
